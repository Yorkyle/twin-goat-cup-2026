## ⚽ What This Is

**GOAT Cup 2026** is a mobile-friendly World Cup experience built as a graduation gift for **Xavier and William**.

It combines:

- a live-feeling **World Cup dashboard**
- a dedicated **Messi / Argentina side**
- a dedicated **Ronaldo / Portugal side**
- video archives
- player guide sections
- favorite game and goal trackers

This is not just a page.  
It is a **summer memory hub** for the 2026 World Cup.

---

## 🔥 Why It’s Cool

This app lets each twin experience the tournament in his own style:

- **Xavier / Messi** → vision, rhythm, control, Argentina
- **William / Ronaldo** → drive, power, mentality, Portugal

The dashboard keeps the tournament front and center, while each player side gives a personalized path through the biggest soccer event in the world.

  - Messi guide mode
  - Argentina watch path

  - save favorite games
